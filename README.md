# Atina II

> Projeto Atina II — espaço central para desenvolvimento, documentação e evolução.

## Estado

O projeto está na fase inicial de estruturação. A tecnologia e os objetivos funcionais serão definidos e registados à medida que o projeto evoluir.

## Objetivos

- Manter o código e a documentação organizados.
- Registar decisões importantes de arquitetura e produto.
- Evoluir em incrementos pequenos e verificáveis.
- Priorizar segurança, qualidade e manutenção.

## Começar

1. Clone o repositório: `git clone https://github.com/lufime/Atina-II.git`
2. Entre na pasta: `cd Atina-II`
3. Consulte `docs/ROADMAP.md` para o planeamento atual.

## Princípios

- Simplicidade e clareza.
- Segurança por defeito.
- Documentação atualizada com as alterações.
- Não guardar credenciais, tokens ou segredos no repositório.
