# Segurança

## Reportar vulnerabilidades
Não publique detalhes de vulnerabilidades por resolver em issues públicas. Contacte o proprietário do repositório através dos canais privados do GitHub para reportar problemas de segurança.

## Regras de segurança
- Nunca adicionar tokens, passwords, chaves privadas ou credenciais ao Git.
- Utilizar variáveis de ambiente para segredos e manter ficheiros locais fora do controlo de versões.
- Validar entradas e limitar permissões ao mínimo necessário.
- Manter dependências atualizadas e rever alertas de segurança.
