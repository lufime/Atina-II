# ATINA — pré-visualização isolada

Esta pasta contém uma cópia visual do jogo e das páginas administrativas para revisão de interface.

## Segurança desta pré-visualização
- Não está ligada ao Supabase de produção.
- No jogo, as chamadas ao backend estão desativadas e a configuração de ligação foi removida.
- As páginas administrativas são apenas visuais: os scripts e operações de gestão foram removidos.
- Não introduzir credenciais, tokens, chaves ou dados reais.
- Não existe publicação nem alteração do site oficial nesta branch.

## Conteúdo
- `index.html`: aplicação do jogador, incluindo as áreas internas.
- `administrator.html` e restantes páginas `admin-*.html`: páginas de administração em modo de leitura.
- `assets/`: estilos e recursos necessários à apresentação.

## Limitações
Esta pré-visualização permite rever estrutura e aspeto visual. Login, dados, partidas, uploads, gestão de imagens e restantes operações ligadas ao backend não funcionam aqui.
